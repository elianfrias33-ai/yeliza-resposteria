# Yeliza Bizcochos y Algo Más — Web

Proyecto Vite. Hecho por NOVIX Studio.

## Trabajar en tu computadora
npm install
npm run dev

## Cambiar datos (horario, teléfono, fotos…)
Edita solo `src/datos.js`. Las fotos van en `public/fotos/`.

## Publicar
Sube los cambios a GitHub. Vercel detecta Vite solo:
- Build Command: `npm run build`
- Output Directory: `dist`
